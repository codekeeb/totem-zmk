# Totem - ZMK Firmware

Firmware ZMK para el teclado split **Totem**.

## 📋 Especificaciones

| Característica | Especificación |
|----------------|----------------|
| Modelo | Totem |
| Firmware | ZMK |
| Layout | Split column-staggered 3×5 + 3 thumb keys (38 teclas) |
| Switches compatibles | Kailh Choc (Low Profile) |
| PCB | Totem |
| Wireless | Soportado (Seeed XIAO BLE, nice!nano, etc.) |
| Conexión | BLE (inalámbrico) o USB-C |
